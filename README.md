# A股市场情绪日报网页

这是“A股市场情绪日报”的公开只读网页版本。数据来源：Wind。

公开网址：https://qrq3838.github.io/a-share-market-sentiment-dashboard/

## 更新逻辑

1. 服务器更新 Wind 数据。
2. 首次运行建立自 2016-01-04 起的日度聚合归档；日常运行只重查最近 7 个自然日并增量追加。
3. 只有行业、个股成交聚合和四个指数全部完整时才采用该交易日；当天 16:30 前不会采用当日数据。
4. 服务器生成单页 `index.html` 后提交到 GitHub，GitHub Pages 自动更新。
5. 数据日期和公开指标未变化时不会重复提交。

主页的市场拥挤度图覆盖全部完整归档历史，可选择任意开始日期、结束日期或快捷区间。四指数图包括上证指数、沪深300、创业板指和科创50，展示各指数的原始收盘点位。
“行业成交结构”中的单个行业成交额占比图支持31个申万一级行业切换，并可选择任意日期区间；所有趋势图横轴均显示完整年份。

数据来源：Wind。

## 安全与口径

- 不上传原始工作簿、SQL 登录信息或服务器私钥。
- 仅发布最新完整交易日成交额前5%的个股榜单，不发布完整个股历史数据。
- GitHub 发布使用该仓库专属的服务器部署密钥，密钥不写入仓库。
- 页面仅供研究交流，不构成投资建议。

## 服务器更新

在服务器运行 `UpdateWebsiteFromSql.ps1` 会执行增量查询、完整性检查、网页生成并推送 GitHub。仅在需要重建全部历史聚合时使用 `-ForceFull`。
