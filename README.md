# A股市场情绪日报网页

这是“A股市场情绪日报｜Wind 日更版”的公开只读网页版本。

公开网址：https://qrq3838.github.io/a-share-market-sentiment-dashboard/

## 更新逻辑

1. 工作簿先刷新 Wind 数据并执行完整性检查。
2. 只有行业成交、个股截面和四个指数全部完整时，工作簿才归档当天数据。
3. 网页读取四张历史归档表共同完整的最后一个交易日。
4. 生成独立 `index.html` 后提交到 GitHub，GitHub Pages 自动更新。
5. 数据日期未变化时不会重复提交。

日报总览的市场拥挤度、四指数和行业趋势图展示最近60个完整交易日，日期按升序且不重复。四指数图包括上证指数、沪深300、创业板指和科创50，均以区间首日归一化为100。
`trends.html` 提供任意开始日期、结束日期和行业选择，覆盖全部完整归档历史；所有趋势图横轴均显示完整年份。

四个指数均直接读取工作簿的存量与增量归档；网页更新过程不再调用外部行情接口。

## 安全与口径

- 不上传原始工作簿。
- 不发布个股级数据，只发布聚合后的市场、指数和行业指标。
- GitHub 凭据由系统凭据管理器保存，不写入脚本。
- 页面仅供研究交流，不构成投资建议。

## 本机更新

运行 `UpdateWebsite.ps1` 可重新生成网页；加上 `-RefreshWorkbook` 会先调用工作簿归档宏。
连接 GitHub 仓库后运行 `InstallDailyUpdate.ps1`，可安装工作日 16:45 的自动更新任务。
